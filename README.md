# Controle Financeiro — Sua Mesa

App web (HTML/CSS/JS puro, sem backend) para controle financeiro da Sua Mesa: DRE, fluxo de caixa e lançamentos. Os dados ficam salvos no `localStorage` do próprio navegador/dispositivo — use a aba **Backup** dentro do app para exportar/importar.

## Usar no navegador

Acesse a página publicada pelo GitHub Pages deste repositório.

## Instalar como app no iPhone

1. Abra o link do GitHub Pages no **Safari** do iPhone (precisa ser no Safari, não funciona pelo Chrome no iOS).
2. Toque no ícone de **Compartilhar** (quadrado com seta para cima).
3. Toque em **Adicionar à Tela de Início**.
4. Confirme o nome e toque em **Adicionar**.

O ícone aparece na tela de início e abre em tela cheia, como um app nativo. Como os dados ficam no armazenamento local do navegador, use a aba Backup periodicamente para não perder os lançamentos.
